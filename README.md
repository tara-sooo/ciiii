# Four Rational Distances: computational search

This repository searches for a point in the Euclidean plane at rational distances from all four vertices of a unit square. The mathematical problem remains open. **Failure to find a point is not a proof of nonexistence.**

## Exact equations

A candidate P=(X/Q,Y/Q), for integers X,Y and positive Q, succeeds iff each of

```
X^2 + Y^2                 = A^2
(Q-X)^2 + Y^2             = B^2
X^2 + (Q-Y)^2             = C^2
(Q-X)^2 + (Q-Y)^2         = D^2
```

holds for integers A,B,C,D. We verify squares with integer arithmetic, not floating-point comparisons.

## Two-stage algorithm

1. `src/enumerate.cpp` enumerates **all ordered pairs of primitive Pythagorean triples** generated by Euclid parameters `2 <= m <= max_m` in the designated partition, restricting to pairs with at least one parameter `m > min_new_m` (not all rational coordinates). For triples `(a,b,h)` and `(c,d,k)` in either leg orientation, set `X=ad`, `Y=bd`, `Z=bc`, `Q=X+Z`, `V=Q-Y`. Two distances are immediately rational. For `Y<Q`, the third is rational iff `X^2+V^2` is a square, checked by exact 128-bit arithmetic after quadratic-residue sieves modulo `64, 5, 7, 11, 13`. Then test `Z^2+V^2` exactly. Persist the three-distance seeds in `seeds.json`.
2. `src/orbits.py` takes each three-distance seed and writes its primitive slope `(a,b)` with `a^2+b^2=h^2`, so P=(at,bt). Setting `sqrt(h^2*t^2-2at+1)=1+st` gives `t=2(s+a)/(h^2-s^2)`. Rationality of the third distance is equivalent to a rational point on the genus-one quartic

   ```
   w^2 = (h^2-s^2)^2 - 4*b*(s+a)*(h^2-s^2) + 4*h^2*(s+a)^2.
   ```

   A quadratic polynomial `w = lead*s^2 + B*s + C` (`lead=+1` or `-1`) tangent to the quartic at a rational point intersects the quartic at another rational point. Iteration generates large-denominator **exact** three-distance points, including points outside the square. Every generated candidate is checked against all three integer-square identities, and the fourth distance is tested exactly.

The walk is not exhaustive: it visits a finite subset of rational points on specific genus-one curves. An arbitrarily small *approximation* to a rational fourth distance does not imply an exact solution.

## Run locally

```bash
g++ -O3 -std=c++20 -Wall -Wextra -o enumerate src/enumerate.cpp
./enumerate --self-test
python3 src/orbits.py --self-test
./enumerate --max-m=120 --output=seeds.json
python3 src/orbits.py --seeds=seeds.json --depth=5 --max-q-bits=2048
```

The regression test includes the known point `(45/52,24/52)` with distances `51/52`, `25/52`, `53/52`, `sqrt(833)/52`. Both programs require only a standard C++20 compiler and Python 3 standard library. Parameters and resource caps are validated.

## GitHub Actions campaign

The workflow runs daily at 02:23 UTC, on source changes to `main`, and via manual dispatch. Four shards process disjoint slices of the ordered-triple-pair search space. The scheduled campaign has **non-overlapping parameter bands** (at least one triple uses an Euclid parameter from the newly added band):

| Scheduled UTC dates | Pair coverage | Partitions |
|---|---|---|
| Nov 22–Dec 19, 2026 | all pairs with `m1,m2 <= 900` | 28 days × 4 shards |
| Dec 20, 2026–Jan 16, 2027 | `max(m1,m2)` in `(900,1100]` | 28 days × 4 shards |
| Jan 17–Mar 13, 2027 | `max(m1,m2)` in `(1100,1500]` | 56 days × 4 shards |

These three phases together cover all ordered pairs of primitive Pythagorean triples with Euclid parameters at most 1,500, in a disjoint partition, **not all rational coordinates or all bounded denominators**. Later scheduled jobs skip work. Manual runs remain configurable. The first phase alone covers about **108 billion ordered pairs** across 28 days. The initial push-triggered run is additional to the campaign.

Each job is limited to 12 minutes, and the C++ program refuses a partition with more than 4 billion pairs. The quartic walk limits the depth (5), denominator bit size (2,048 by default), and processed states (50,000). Runners are ordinary GitHub-hosted Ubuntu machines; no privileged tokens, third-party downloads, or paid services are used. The repository is public, so ordinary GitHub Actions hosted-runner minutes do not incur GitHub Actions usage charges under the current public-repo policy.

`seeds.json`, `orbits-summary.json`, compressed `orbits.jsonl.gz`, and logs are uploaded as artifacts for 30 days. The workflow marks a run as failed and prints an alert if any exact four-distance candidate is found, so the candidate can be independently checked. The YAML token permission is `contents: read`.

The complete JSONL dataset contains exact integer numerators and denominators, not just approximations. Results are never described as an exhaustive exclusion over all denominators, nor as a new theorem.
